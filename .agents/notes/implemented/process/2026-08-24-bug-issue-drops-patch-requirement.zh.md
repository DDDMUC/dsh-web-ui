# Agent Note: Bug issues drop the required patch

Status: implemented

## Problem

Bug 问题表单要求提交者必须提供建议补丁（`补丁`），Issue 模板执行工作流还会关闭没有补丁的报告。这让一份可复现的 Bug 报告依赖提交者已经完成问题定位并提出修复方案，既不是判断可维护性的可靠信号，也提高了普通用户提交的门槛。

## Decision

Bug 报告不再包含补丁字段，也不再要求补丁。Bug 表单继续把截图证据、冒烟测试证据和代码引用作为必填字段，Issue 模板执行工作流也只校验这些部分。`standard_issue.yml`、`CONTRIBUTING.md` 和 `ISSUE_TRIAGE.md` 现在按同样要求描述，不再要求或承诺补丁。

提交者如果已经有修复建议，仍可在补充信息中附带。

## Alternatives considered

- 保留补丁字段但改为可选：否决，因为表单不应把未经充分思考的补丁纳入 Bug 报告的最低要求，且用户明确要求只提供冒烟证据。
- 同时移除代码引用要求：否决，因为代码引用仍是轻量的分类辅助信息，并不是用户反馈的障碍。
- 保持模板不变：否决，因为执行工作流会继续关闭已经完整复现的报告。

## Consequences

模板和执行工作流现在接受包含复现步骤、截图、环境信息、冒烟测试证据和代码引用但没有补丁的 Bug 报告。维护者如果后续需要修复方案，可能需要额外追问，这是新增的可选跟进开销。
