# Agent Note: Release v0.3.15 发布记录

Status: implemented

## 问题

全家桶需要覆盖 `v0.3.14..dev` 区间的下一次统一发版：内置 dsh-perf 插件的完全移除（本区间唯一的破坏性变更）、remote-web-ui 面向 docker/反向代理场景的 token 与信任主机配对能力及其加固修复（动态信任主机表加上限、回环代理双向拆除、清理无用的 lanAddresses 依赖）、dsh-web-all 降级路由的引用计数单例修复、跨 skins/settings/web-all/task-board 的四问题修复批（#1368、#1370、#1372、#1359）、新增 blue-throated-bee-eater 皮肤、maid-atelier 与 phoebe-atelier 皮肤 CSS 修复、pet 插件的性能与卸载修复、桌面安装向导（VC 运行库检测与卸载提示）及 desktop-release 打包工作流、dsh-audiogen 社区插件索引收录、release-notes 的 mention 中和修复。

## 决策

按标准全仓统一版本流程发布 v0.3.15（0.3.14 的下一个补丁版本）；用户未指定版本号，适用默认下一补丁规则。兼容性审计结论是该区间可安全自动升级：

- dsh-perf 移除沿用已在生产验证过的 dsh-aionui-panel 移除模式（v0.3.7 发布，此后五个版本反复走过）：聚合包安装引用 `@linxin666/dsh-web-all`，其重新生成的补丁不再挂载 dsh-perf，更新时重渲染 profile 行即完成卸载；`session-persistence-jsonl` 调优补丁回落到官方原生行，无需用户手动操作。单独安装 dsh-perf 的用户可继续使用但包已冻结——release notes 已写明不再发布后续版本。registry 上的包保持已发布状态，market 徽章白名单保留 `@linxin666/dsh-perf`，下载总量不变。
- task-board 的 `model` 字段是同 bundle 的可选线协议扩展：客户端与宿主随同一插件包发布，校验器接受不带该字段的旧载荷，不持久化 `model` 的旧任务依旧合法。settings allowlist 变更把 `market` 同时映射到 `dsh-market` 与 `dsh-web-ui-market` 两个命名空间（旧解析结果的超集，向后兼容）。remote-web-ui 的 token/信任主机选项是纯增量配置面。区间内其余持久化标识符全部冻结。
- 包身份、exports 与 `dsh.engines.dsh` 下限均未变化；dsh-perf 目录删除后家族包数量为 19。

验证证据：bump 前 dev 上全部门禁绿（`sync-shared:check`、`typecheck`、`test`、`test:scripts`、`runtime-deps:check`、`aggregate:check` 为 18 行 / 17 依赖 / 14 客户端子项、`market:check`、`skin-center:check`、`docs:check`、`i18n:check`），19 个家族包版本统一 bump 到 0.3.15，bundle 与市场资产由同一次 bump 构建并一起提交（重建后 `market:check` 通过）。发版提交 `d7ba130a` 落在 `dev`，`main` 快进到同一提交，tag 从 `main` 打出。发布管线（run 33932764652）全程成功耗时 5m47s，包含带门禁的 npm 发布、挂载 + 无头渲染冒烟，以及用已提交双语 notes 创建的 GitHub Release。desktop-release 工作流（run 33932764740）随同一 tag 触发。发布后验证：registry 上 `@linxin666/dsh-web-all` 与 `@linxin666/dsh-client-ui-skin-center` 均为 0.3.15；旧聚合包 `@linxin666/dsh-web-ui-all` 保持 0.3.6 且弃用元数据完好；Release 正文 `user-mention` 计数为 0，远端 tag 指向 `d7ba130a`。

## 备选方案

- 用 minor 版本标记 dsh-perf 移除：否决——家族惯例是统一补丁版本的发版节奏，该移除是带确定性聚合路径迁移的简化，不是功能线。
- 保留 dsh-perf 可安装但移出聚合包：移除决策记录中已否决——孤儿包保留全部维护成本，默认安装却没有用户可达。

## 后果

- npm `@linxin666/*` 全家 19 包统一到 0.3.15；旧聚合包保持弃用状态停在 0.3.6，管线旧包双发步骤保持空操作。
- `dev` 与 `main` 同停 `d7ba130a`，无残余分叉。
- 所有安装失去性能 HUD、归因统计、渲染降级与写入批处理调优；会话由官方原生 `session-persistence-jsonl` 行服务。单独挂载 dsh-perf 的用户保留现有安装但不再收到更新。
- v0.3.15 的桌面安装包由 `desktop-release.yml` 在 tag 推送后自动构建并上传到 GitHub Release；首次 tag 驱动的桌面打包运行为 run 33932764740。
