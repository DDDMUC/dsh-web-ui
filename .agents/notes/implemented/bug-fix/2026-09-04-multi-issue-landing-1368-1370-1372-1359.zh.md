# Agent Note: multi-issue landing for #1368, #1370, #1372, and #1359

Status: implemented

## Problem

收集到涉及皮肤、设置、聚合包挂载与任务看板插件的 4 个问题：

1. **#1368（maid-atelier 与 phoebe-atelier 的 composer 遮挡 SettingsPanel）**：在这两套主题下，底部 composer 容器及 seat 具有较高的层叠上下文和粘性定位，在响应式或固定视口中遮挡了设置对话框和侧栏底栏。
2. **#1370（设置页卡片显示未暴露配置命名空间）**：Web 插件设置页中部分插件卡片显示“未暴露配置命名空间”，原因在于命名空间白名单交集逻辑丢失了规范别名（`dsh-market` 与 `dsh-web-ui-market`，以及官方 `dshmarket` 别名），且插件在旧版宿主 `settings.section` 下缺少容错保护。
3. **#1372（聚合包中子插件停用后未隐藏客户端 UI 入口）**：在聚合包 `dsh-web-all` 中，即使在 `cordis.patch.yml` 中停用或删除了子插件行，由于客户端加载器无差别挂载所有内联子插件，其客户端侧 UI 按钮和入口仍然被渲染。
4. **#1359（任务看板支持按任务指定模型）**：任务支持指定工作区、预设与权限，但无法指定特定的 LLM 模型，用户必须在宿主会话中手动重新切换模型。

## Decision

在一个统一的维护批次中完整解决了上述 4 个问题：

- **皮肤层级修复 (#1368)**：放宽 `maid-atelier/patches.css` 与 `phoebe-atelier/skin.css` 中的选择器匹配。在设置对话框打开时（`body[data-maid-settings-open]` 或 `body[data-phoebe-settings-open]`），强制将 `:is([data-composer-seat], [data-slot="conversation.composer"], [data-composer-card])` 降低至 `z-index: 0 !important`，并将侧栏祖先容器层叠重置为 `z-index: auto !important`，完全释放对话框的交互。
- **设置白名单与回退容错 (#1370)**：在 `dsh-web-settings` 的 `FAMILY_NAMESPACES` 中补齐生态命名空间（`dsh-market`、`usage`、`doctor`、`liangshen`、`session-archive`）。增强 `resolveNamespaceEntries` 支持双向映射与官方别名扩展。在各插件入口中对 `installSection` 增加容错保护与降级回退。
- **聚合子插件激活门控 (#1372)**：在 `dsh-web-all` 客户端挂载逻辑中新增 `CHILD_ROW_IDS` 与 `activeBootEntryIds()` 检查。当 `__DSH_BOOT__.entries` 存在时，仅当子行处于激活状态时才挂载对应的客户端 UI，已停用或删除的子行直接跳过。
- **任务看板按任务指定模型 (#1359)**：在任务协议、更新补丁及存储结构中新增可选的 `model?: string` 字段。在 `HostExecutionRunner` 启动会话时调用 `session.selectModel` 绑定模型，并在 `NewTaskModal` 与 `TaskDetail` 组件中提供模型选择器 UI。

## Alternatives considered

- **通过 JavaScript 钩子手动重新排布对话框层级 (#1368)**：不予采纳，纯声明式 CSS 规则能够干净地管理层叠上下文，避免了生命周期开销与 DOM 突变抖动。
- **在设置白名单中采用严格单字符串匹配 (#1370)**：不予采纳，生态中存在历史别名和官方宿主差异，别名扩展解析器更健壮且向下兼容。
- **将聚合包拆分为独立动态 import 结构 (#1372)**：不予采纳，聚合包设计初衷为高性能内联单文件，基于启动项检查即可精确实现激活门控而无需重构架构。
- **仅在工作区全局层级统一绑定模型 (#1359)**：不予采纳，不同自动化任务对模型能力需求不同（如推理模型与快速编码模型），按任务指定更为灵活。

## Consequences

- 在 maid-atelier 和 phoebe-atelier 皮肤下，设置面板在所有状态下均完全可见且可点击交互。
- Web 插件设置页卡片能稳定匹配配置命名空间，不再出现未暴露提示。
- 在 `cordis.patch.yml` 中停用聚合子插件行后，其客户端 UI 入口被彻底隐藏。
- 任务看板支持为每个任务配置专属模型并在执行时自动切换。
