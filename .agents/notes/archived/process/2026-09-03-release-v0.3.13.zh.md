# Agent Note: v0.3.13 发布

Status: implemented
Archived: 2026-09-04

## 问题

全家桶需要下一次统一发版，覆盖 `v0.3.12..dev` 区间：phoebe-atelier 皮肤批次（新增光弦工坊皮肤并带场景切换、画面精修、光晕与边缘去污修复、恢复 LICENSE/NOTICE、CSS 限定在官方外壳内生效、reviewed 钩子注册表刷新）、remote-web-ui 中继批次（快速隧道改经稳定的单层 dsh-market 子域名中继、必需的 `/*` 路由模式修复、origin Host 标记、以及让配对手机重启后不掉线的命名隧道新模式）、dsh-web-all 子路径行显示名、dsh-perf 移除弃用的 better-session 卡片与 bsm 核心、共享 CSS module 样式标签去冲突与设置卡片对比度提升、以及 ssh 与 task-board 共用的中栏面板挂载核心抽取。

## 决策

按标准统一版本流程发布 v0.3.13（0.3.12 的下一个补丁版本）；用户未指定版本号，适用默认下一补丁规则。兼容性审计将本区间判定为可安全自动升级：

- 本仓库自己定义的持久化与线上标识符均未变化。中继/命名隧道特性为纯增量（新增 remote 的 `tunnelToken` secret 路径、market worker 的新中继注册表与 D1 迁移 0007）；设置 section id、API path、存储 key 均未改变。
- dsh-web-all 子路径导出改动仅影响展示：家族行仍通过 `config.plugin` 挂载相同模块；marker manifest（`lib/shells/package.json`，无 `dsh` 字段、type module）只是让客户端扫描器避免重复挂载。
- better-session 移除会去掉 dsh-perf 的 Better Session 卡片与 bsm 核心（旧会话迁移面）；引用它们的 profile 失去该卡片，会话存储仍由原生 jsonl 负责。
- CSS module 样式标签 id 变化（由 basename 改为完整仓库相对路径）属于 bundle 内部实现；没有任何持久化 key 或 loader id 依赖旧的同名冲突命名。
- 旧聚合包双发窗口保持关闭：`@linxin666/dsh-web-ui-all` 维持 0.3.6 弃用状态，该管线步骤对 0.3.13 为 no-op。

验证证据：全套门禁绿（`typecheck`、`test`、`test:scripts`、`runtime-deps:check`、`aggregate --check`、`market:check`、`skin-center:check`、`docs:check`、`i18n:check`），19 个家族包版本全部 bump 到 0.3.13，bundle 与市场资产由同一次 bump 重建并一起提交，发布管线（run 33698660992）端到端成功，包括门控 npm 发布、挂载冒烟、以及用已提交双语 notes 创建的 GitHub Release。发布后验证确认每个可发布的家族包在 registry 上都是 0.3.13（包括以 client-ui 名义而非目录名发布的 `@linxin666/dsh-client-ui-market`），GitHub Release 上双语正文齐全。

这次分支处理干净：`dev` 携带 bump 提交 823a334e（amend 一次并入双语 notes），`main` 从 fc8896cc 快进到 823a334e，tag 从 `main` 打出，`main` 合回 `dev` 后两分支都停在 823a334e。

## 备选方案

- 因为每个功能都已提前合入 dev 而跳过兼容性审计：拒绝——审计是发布门禁而非合入门禁，better-session 卡片移除与样式标签 id 变化都需要显式迁移结论（两者均判定为向后兼容、无需持久化标识符映射）。
- 因命名隧道新特性而用 minor 版本：拒绝——全家桶的惯例是统一版本的逐补丁发版节奏，且该特性是可选 secret 后面的纯增量。

## 后果

- npm `@linxin666/*` 全家桶进入 0.3.13；旧包 `dsh-web-ui-all` 维持 0.3.6 弃用。
- `dev` 与 `main` 都停在 823a334e，无残留分叉。
- 命名隧道模式与中继注册表已对用户可用，但运行中的 DSH 服务仍需用户自行重启、market worker 需另行部署才能用上新的中继 API 面；本次发布只交付代码。
- Release notes 为已入库的双语 `docs/release-notes/v0.3.13.md`（中文默认视图、English 折叠视图）；管线采用了该文件。
